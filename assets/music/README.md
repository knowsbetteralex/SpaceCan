# Музыка SpaceCan (AYM1)

Замените расположенные здесь файлы своей музыкой из MIDI2AYM1:

- `title.aym` — вступительная музыка, запускается после обязательной
  биперной заставки; рекомендуется включённый loop.
- `game.aym` — фоновая игровая музыка, не сбрасывается после потери жизни;
  рекомендуется включённый loop.
- `game_over.aym` — музыкальная концовка; рекомендуется loop=0.

**Не нужно менять** `music.asm` или процедуру плеера, если
сохраняются имена файлов. После замены выполните сборку `main.asm`
из корня репозитория.

Каждый файл — **полный бинарный AYM1 v1** с заголовком
16 байт (`AYM1`, FPS=50, флаги loop, полный размер, смещение цикла,
частота AY) и командами FRAME/WAIT/END. Обычный MIDI, VGM,
YM и другие музыкальные форматы напрямую не подходят.
Сведения: [../../docs/aym1_format.md](../../docs/aym1_format.md).

Важные параметры конвертации:
- 50 кадров/с;
- частота AY должна соответствовать реальному чипу;
  демофайлы экспортированы на **2 000 000 Гц**;
- до трёх независимых тональных каналов AY;
- перекрытие MIDI-нот разрешается на стороне конвертера;
- вся музыка `INCBIN`-включается в оперативную память ZX 48K
  в конце кода, поэтому следите за свободной памятью.

По умолчанию здесь сохранены **короткие демомелодии из прежнего
`music.asm`**, чтобы проект работал до добавления собственных треков.
Развёрнутая версия `space_step18_standalone.asm` тоже читает эти
файлы извне. Старые standalone остаются архивными снимками.
