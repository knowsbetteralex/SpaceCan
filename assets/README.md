# SpaceCan: графика экранов ZX Spectrum 48K

Ресурсы сохранены в **нативном формате `.scr`** — строго 6912 байт, без заголовков, с естественным расположением экранной памяти ZX Spectrum.

| Файл | Что содержит |
| --- | --- |
| `spacecan_background.scr` | Чистый экран: банка Space Soda, стена, светильники, барная стойка и чёрный игровой коридор X=8..23 |
| `spacecan_title.scr` | Тот же экран, поверх центрального коридора — SPACECAN (пиксельные 16×16 буквы), SPACE SODA 48K, 0.33L, управление и PRESS ANY KEY / TO START |

Размер: **256×192**, два цвета на знакоместо **8×8**, ZX-атрибуты `INK/PAPER/BRIGHT`. Битовая карта занимает первые **6144** байт, атрибуты — последние **768**.

## Важно для работающей игры

Действующий `main.asm` **не делает INCBIN этого `.scr`**. В игровом бинарнике уже есть эквивалентный сжатый фон `artwork.asm`, который распаковывается процедурой `LOAD_SPACE_CAN_SCREEN` в `ui.asm`. Стартовое меню динамически рисуется в `menu.asm`, поэтому `PRESS ANY KEY` может мигать, не требуя второго полного экранного буфера.

`spacecan_background.scr` — точный экспорт распакованного `artwork.asm`.
`spacecan_title.scr` — отдельно сохранённый статичный экран-референс для дальнейшего редактирования и проверки отображения на ZX Spectrum.

Открывайте `.scr` в редакторе ZX Spectrum SCREEN$ или в эмуляторе, поддерживающем загрузку экранных файлов. Это **не** TAP/TZX: сырой `.scr` не содержит BASIC-заголовка для `LOAD "" SCREEN$`; для загрузки с ленты нужна упаковка в соответствующий формат.

## Пример экрана: меню + HUD со счётом 999999

- [spacecan_title_menu_hud_999999.scr](spacecan_title_menu_hud_999999.scr) — полноценный готовый ZX Spectrum `.scr` (6912 байт): актуальный бело-голубой SPACECAN 16×16, надписи меню из `menu.asm`, верхняя панель (SPEED 3, четыре заполненных красных сердца, 999999 очков, десять зелёных делений штрафа).
- [spacecan_title_menu_hud_999999.png](spacecan_title_menu_hud_999999.png) — PNG-предпросмотр 256×192.

Это статический **макет экрана** для открытия в эмуляторе/редакторе: в исполняемой игре меню и игровая панель обычно показываются на разных экранах. Здесь они совмещены по запросу, игровая логика не менялась.
