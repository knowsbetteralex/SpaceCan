# Музыка SpaceCan (AYM1 и AYM2)

Замените расположенные здесь файлы своей музыкой из MIDI2AYM1:

- `title.aym` — вступительная музыка, запускается после обязательной
  биперной заставки; рекомендуется включённый loop.
- `midiver1.aym` — **основная игровая музыка AYM2 v1**, не сбрасывается после потери жизни;
  включён loop. Исходный `midiver.aym` (AYM1) сохранён для сравнения.
- `main_menu1.aym` — **музыка меню AYM2 v1**, запускается после биперной заставки;
  включён loop. Исходный `main_menu.aym` (AYM1) сохранён для сравнения.
- `game_over.aym` — тестовая мелодия поражения, loop=0.
- `victory.aym` — отдельная тестовая победная фанфара, loop=0.

Биперная мелодия звучит перед финальным AY-треком. Основной игровой трек `midiver.aym` сохранён.

**Текущая сборка подключает именно** `main_menu1.aym` и `midiver1.aym` (**AYM2**) вместе с `game_over.aym` и `victory.aym` (**AYM1**) через `music.asm`. Старые `title.aym`, `game.aym` и большой `gol.aym` хранятся для экспериментов, но в актуальный TAP **не входят**.

**План экономии памяти:** [замеры и требования к будущему AYM2](../../docs/aym_compression_analysis.md), а также [ТЗ конвертера MIDI2AYM1](https://github.com/knowsbetteralex/MIDI2AYM1/blob/main/docs/aym2_compression_spec.md). Теперь плеер поддерживает оба формата: AYM2 v1 с короткими командами и словарём, а также AYM1 v1 для старых треков. Процедурные инструменты и повторяемые фразы пока не реализованы. План разделяет точное словарное сжатие без изменения звука и эксперименты с процедурными огибающими и повторяющимися фразами.

**Не нужно менять** `music.asm` или процедуру плеера, если
сохраняются имена файлов. После замены выполните сборку `main.asm`
из корня репозитория.

В формате **AYM1** заголовок 16 байт (`AYM1`), а в **AYM2 v1** — 24 байта (`AYM2`),
после которых идут FRAME/WAIT/END, короткие команды и словарные токены.
Формат определяется по сигнатуре автоматически. Нельзя использовать произвольный сжатый файл
без предварительной валидации конвертером/тестами. Спецификация:
[AYM2 v1](https://github.com/knowsbetteralex/MIDI2AYM1/blob/main/docs/aym2_format.md). Обычный MIDI, VGM,
YM и другие музыкальные форматы напрямую не подходят.
Сведения: [../../docs/aym1_format.md](../../docs/aym1_format.md).

Важные параметры конвертации:
- 50 кадров/с;
- частота AY должна соответствовать реальному чипу;
  демофайлы экспортированы на **2 000 000 Гц**;
- до трёх независимых тональных каналов AY;
- перекрытие MIDI-нот разрешается на стороне конвертера;
- вся музыка `INCBIN`-включается в оперативную память ZX 48K
  в конце кода, поэтому следите за свободной памятью.

По умолчанию здесь сохранены **короткие демомелодии из прежнего
`music.asm`**, чтобы проект работал до добавления собственных треков.
Развёрнутая версия `space_step18_standalone.asm` тоже читает эти
файлы извне. Старые standalone остаются архивными снимками.
